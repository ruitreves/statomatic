# Set rownames to a specified column and remove that column from the dataframe

Set rownames to a specified column and remove that column from the
dataframe

## Usage

``` r
cf(dat, column_index = 1)
```

## Arguments

- dat:

  a data.frame

- column_index:

  the index of the column you want as your rownames, defaults to 1

## Value

the original data frame with the row names set as specified and the
specified column removed
